
  # SaaS Web App UI Design (Copy)

  This is a code bundle for SaaS Web App UI Design (Copy). The original project is available at https://www.figma.com/design/zObUDxepEqXr6IZQUYkkJb/SaaS-Web-App-UI-Design--Copy-.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` from the project root to start the frontend and backend together.

  If you only want one side, use `npm run dev:frontend` for the Vite app or `npm run dev:backend` for the API.

  ## Backend

  A starter Express + MongoDB backend lives in `backend/`. Run `npm install` inside that folder after copying `backend/.env.example` to `backend/.env`, then use `npm run dev` to start it.
